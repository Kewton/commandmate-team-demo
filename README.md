# commandmate-team-demo

A throwaway repository used to record a [CommandMate](https://github.com/Kewton/CommandMate) run:
a person on a phone talks to a PM agent, the PM hands the issues to a dev lead, the dev lead runs
`cmate-orchestrate`, and Command Code workers implement each issue in its own Git worktree under a
contract. Gates decide what is done. See `CLAUDE.md` for the roles and the runbook.

Nothing here is meant to be used as a library.
